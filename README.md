# DataAnalystAI

An AI-powered Data Analyst Agent built with:

- FastAPI
- LangGraph
- Ollama
- Llama 3.2
- Pandas
- DuckDB
- Plotly
- Streamlit

Features:

- Upload CSV and Excel files
- Ask questions in natural language
- Automatic data cleaning
- Interactive charts
- SQL querying
- AI-generated insights
- Report generation
